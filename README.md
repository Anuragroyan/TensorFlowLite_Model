🤖 Sarcasm Detector
Sarcasm Detector is a Kotlin-based Android application that uses a TensorFlow Lite (TFLite) machine learning model to analyze user-provided text and determine whether the text contains sarcasm. The app performs machine learning inference directly on the device, without requiring a backend server.

✨ Features
* 🤖 Sarcasm detection using machine learning
* 📝 User text input
* 🧠 TensorFlow Lite model integration
* 📱 On-device ML inference
* 🔤 Text classification
* ⚡ Real-time prediction results
* 🎨 Jetpack Compose UI
* 🔒 No backend required
* 📊 Clear prediction result display

🛠️ Tech Stack
* Kotlin – Android application development
* Jetpack Compose – Modern declarative UI
* TensorFlow Lite – On-device machine learning
* TFLite Text APIs – Text processing and classification
* Android SDK – Native Android development

🎯 Project Purpose
This project demonstrates how a machine learning model can be integrated into a native Android application using Kotlin and TensorFlow Lite. It focuses on on-device text classification, allowing predictions to be performed locally without depending on a backend service.
